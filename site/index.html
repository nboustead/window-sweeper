WHAT IT DOES

One list, four apps
Excel, Word, classic Outlook, and Chrome, each with its own icon and accent color.
Live safety re-check
Save state is re-read at the moment of closing, not from a stale refresh - an unreadable state is always treated as unsaved.
Single-click or batch
Act on one row, or Save & Close All / Close All Saved / Close All and Discard - the discard batch always lists what it will touch first.
Never launches anything
Attaches only to apps already running. Refreshing or listing never starts Excel, Word, Outlook, or Chrome.
Chrome tabs, opt-in
Off by default. Point it at a Chrome debug port to list and close individual tabs instead of whole windows.
Action log
Every save/close/discard is recorded to a local CSV - one row per action, on your machine only.

REQUIREMENTS

  • Windows 10 or 11, with Windows PowerShell 5.1 (included - not PowerShell 7 / pwsh).
  • Desktop Excel and/or desktop Word, for those rows to appear.
  • Classic desktop Outlook for Outlook rows - the new Outlook (UWP/web rewrite) does not support the automation this tool relies on.
  • Chrome is optional and off by default.

INSTALL

  1. Download the zip above and extract it anywhere.
  2. Right-click the zip -> Properties -> check Unblock -> OK - then extract it (see the FAQ below for why).
  3. Double-click Run-WindowSweeper.bat.

FAQ

Windows is warning me about the download - is this safe?
Yes - this is Windows SmartScreen or the Attachment Manager flagging any file downloaded from the internet, not a problem specific to this tool. Right-click the zip, open Properties, check Unblock, click OK, then extract it. If you already extracted it and still see a warning when running the tool, unblock the zip, delete the extracted copy, and extract again.
Do I need to change my PowerShell execution policy?
No. Run-WindowSweeper.bat already launches PowerShell with -ExecutionPolicy Bypass for its own child process only - it does not change any policy on your machine, and there is nothing to configure yourself.
Does this send anything over the network?
No. The only network activity is a loopback (127.0.0.1) HTTP call to a Chrome debug port, and only if you explicitly configure one in settings.json. Nothing else is contacted, ever.
Privacy: 100% local. No telemetry, no accounts, no network calls except the loopback Chrome debug port(s) you configure yourself. Logs stay on your machine under %USERPROFILE%\.window-sweeper\logs\.
